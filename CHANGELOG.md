# Changelog

All notable changes to NTERO are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses calendar versioning.

## 2026.8.18 - 2026-08-24

### Added

- Extract, update, rebuild, and overlay workflows for EverQuest S3D textures.
- Editable PNG texture workflow with alpha-profile validation.
- Editable FLAC sound workflow that restores the original PCM WAV profile.
- Incremental archive packing and resumable pack-state checkpoints.
- Python 3.14 command-line package, native Rust encoder, and standalone Windows
  executable support.
